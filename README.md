# Krishna Taneja — Engineering Portfolio

A personal portfolio website showcasing my engineering projects across software, AI/ML search algorithms, and hardware. Built using HTML, Dart Sass (SCSS), and vanilla JavaScript.

## What I Work On
- **Software & Web Development:** Building web applications, REST APIs, user authentication, and SQL databases.
- **AI/ML & Algorithms:** Using Depth-First Search (DFS) with backtracking to solve timetable scheduling and constraint problems.
- **Automation & Tools:** Writing Python scripts to automate background tasks and monitor lab computer systems.
- **Hardware & Embedded Projects:** Writing microcontroller code in C/C++ (Arduino, ESP), wiring sensors on breadboards, and testing circuits.

---

## How to Run the Project

### 1. Install Dependencies
```bash
npm install
```

### 2. Start the Local Server & Watch Sass
```bash
npm start
# or
npm run dev
```
This runs the local server at `http://127.0.0.1:8080` and watches SCSS files for changes.

### 3. Compile Sass Once
```bash
npm run build:sass
```
